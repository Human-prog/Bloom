# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Bloom Notch takes security seriously. If you believe you have found a security
vulnerability, please report it responsibly.

**Do not** open a public GitHub issue for security concerns.

Instead, contact the maintainer through one of these channels:

- **GitHub Security Advisory:** Use the "Report a vulnerability" button on the repository
- **GitHub Issue:** https://github.com/Human-prog/Bloom/issues/new?template=security_report.md

## What to Include

Please include as much of the following as possible:

- Type of issue (e.g., injection, authentication, data exposure)
- Full paths of affected files
- Steps to reproduce
- Proof-of-concept or screenshots (if safe to share)
- Impact assessment

## Response Timeline

- **Acknowledgment:** Within 3 business days
- **Initial assessment:** Within 7 business days
- **Resolution or status update:** Within 14 business days

## Disclosure Policy

We follow coordinated disclosure. We will not disclose a vulnerability publicly
until a fix is available or you have given explicit permission. We will credit
you in the release notes unless you request anonymity.

## Safe Harbor

Security researchers acting in good faith are granted safe harbor. We will not
pursue legal action against you for good-faith security research conducted
against Bloom Notch.
