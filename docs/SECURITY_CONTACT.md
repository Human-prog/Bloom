# Security Contact

Report security vulnerabilities to the Bloom Notch maintainer.

## Preferred Channels

1. **GitHub Security Advisory:** Use the "Report a vulnerability" button on the repository
2. **GitHub Issue:** https://github.com/Human-prog/Bloom/issues/new?template=security_report.md

## What to Include

- Issue type (injection, auth bypass, data exposure, etc.)
- Affected file paths and line numbers
- Steps to reproduce
- Proof of concept (if safe to share)
- Impact assessment

## Response

We acknowledge all good-faith reports within 3 business days and provide
coordinated disclosure credit upon request.
